# 小空间设计原则

> 公寓酒店 / studio 单元（25–60㎡）跨功能区通用知识。功能区特定策略在 `soft_zoning.md` 与各 Skill 中定义。
> 约束层级：**【必须】**不可违反 · **【建议】**默认遵守，可说明理由后偏离 · **【提示】**鼓励灵活处理

## 一、小空间与普通住宅的根本区别

| 维度 | 普通住宅（interior-layout） | 小空间（本 plugin） |
|------|------|------|
| 空间结构 | 多个封闭房间，墙界清晰 | 一个开放主间 + 一个封闭卫生间 |
| 功能关系 | 每个房间单一功能 | 睡 / 工作 / 烹饪 / 休闲在同一空间叠加共存 |
| 布置逻辑 | 家具靠房间的墙锚定 | 家具围绕功能软区组织，**不必靠墙** |
| 核心矛盾 | 把家具摆好看 | 在有限面积里塞下所有功能且不互相挤死 |
| 设计价值 | 风格 + 舒适 | **功能复用 + 空间效率 + 可复制** |

> **【必须】**不要把开放主间当成"一个大房间"逐面墙摆家具——那会退化成几堆互不相关的贴墙家具，丢掉小空间真正的设计价值。

## 二、小空间四大设计杠杆

1. **多用途家具**：一件家具承担多功能（沙发床=坐+睡、餐桌=吃+工作、墨菲床=睡+收起后腾出地面）。优先选多用途件压缩总占地。
2. **竖向储物**：地面寸土寸金，储物尽量上墙、到顶。壁挂、吊柜、高柜优先于落地矮柜。
3. **功能时分复用**：同一块地面在不同时段承担不同功能（白天工作区 / 夜间睡眠区）。软分区阶段要显式声明复用关系。
4. **动线最小化**：开放空间动线应短而直。一条贯穿主通道（≥800mm）串起所有功能区，避免绕行。

## 三、空间硬约束（与平台 validate_layout 对齐）

**【必须】**任何家具不可违反——违反任一条 validate_layout 报 error：
1. bounds 完全在设计区边界内（越界 = 穿墙）
2. bounds 不与禁区（柱 / 管井）重叠
3. bounds 不与其他模块重叠
4. 不阻挡门 / 卫生间门的开启扇区

> 设计区边界已扣除墙面完成面厚度，直接以它为可用范围，**不要**再额外预留。

## 四、通道与间距

| 间距类型 | 最小宽度 | 场景 |
|----------|---------|------|
| 主通道 | ≥ 800mm | 贯穿开放主间的主动线（小空间可比住宅 900mm 略压缩）|
| 次通道 | ≥ 600mm | 家具间穿行 |
| 床 / 沙发使用侧 | ≥ 500mm | 上下床、起身 |
| 操作净空（橱柜前 / 书桌前）| ≥ 700mm | 下蹲取物、拉椅起身 |

**通行间隙 vs 使用间隙**：通道标准只适用于"人需要从此处走过到达其他区域"的间隙；人在旁边伸手操作即可的间隙无最低通道要求。

**【建议】**小空间慎留 <600mm 的边角窄缝——既非通道也非储物，是卫生死角。宁可把家具贴靠到底消除窄缝，或把窄缝合并进通道。

## 五、布置优先级

锚点 → 主要 → 可选，与软分区配合：

| 层级 | 定义 | 小空间典型 |
|------|------|-----------|
| 锚点 | 占地最大 / 最难移动 | 睡眠件（墨菲床 / 沙发床）、厨房台 |
| 主要 | 功能必须 | 储物、工作面 |
| 可选 | 锦上添花 | 单椅、边几、装饰 |

WHY：先把占地大的锚点件在软区里定位，再用主要/可选件填充，避免大件最后无处安放。

## 六、家具依赖（成套同阶段放置）

| 依赖组 | 组成 |
|--------|------|
| 睡眠组 | 床（或墨菲/沙发床）+ 床头收纳（小空间常省略独立床头柜，用壁挂搁板替代）|
| 工作组 | 书桌 + 椅子（椅子可收纳到桌下，紧张时算附属件）|
| 餐厨组 | 餐桌 + 椅 + 厨房台（开放式厨房与餐区常合并）|
| 休闲组 | 沙发 + 茶几（茶几在小空间可选 / 用折叠边几替代）|

**功能互斥**：同一功能不重复（不放两张床）；但**时分复用不算重复**——墨菲床收起后该地面变休闲区是合法复用，需在软分区里声明。

## 七、修正优先级（验证失败时）

**平移** → **旋转** → **换更小 / 可折叠模块** → **拆除附属件（椅子等）** → **改用多用途件合并功能** → **移除可选件**

WHY：小空间修正比住宅多一档"改用多用途件合并功能"——当空间实在放不下独立的睡+坐时，换墨菲床/沙发床把两功能合并，比直接移除某个功能更优。
