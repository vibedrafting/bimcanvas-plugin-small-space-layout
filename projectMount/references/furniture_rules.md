# 小空间家具选品规则

> 配合 `module_library.json` 使用。模块库定义每件家具的能力与 agent_config；本文件是跨家具的选品策略。

## 一、选品优先级（小空间专属）

1. **多用途 > 单用途**：墨菲床 > 普通床；沙发床 > 沙发 + 床；可升降餐桌 > 餐桌 + 茶几。
2. **可折叠 / 可收纳 > 固定**：折叠桌、嵌套凳、可推拉。用时展开，不用时收起腾地面。
3. **壁挂 / 到顶 > 落地矮件**：储物上墙、吊柜到顶，把地面留给活动。
4. **参数化可调 > 固定尺寸**：定制柜体按可用墙长伸缩，吃满空间不留死角。

## 二、各功能区选品要点

### 睡眠
- 首选 **墨菲床（翻折床）**：收起后该区变休闲/工作区（时分复用）。占地按"展开态"算 bounds，软分区需声明复用。
- 次选 **沙发床**：坐卧两用，适合休闲与睡眠共享同一区。
- 真正放得下独立床时才用固定床；小空间慎用 1800 床，1200/1500 优先。
- 床头柜常省略，用**壁挂搁板**替代。

### 工作
- **可折叠壁挂书桌** / 窄深书桌（深度 ≤ 500mm）靠窗，蹭自然光。
- 椅子选可收纳到桌下的款，紧张时算附属件（可拆除）。
- 餐桌兼工作台是常见共享方案。

### 烹饪（开放式厨房）
- **一字型 / L 型紧凑厨房台**，沿卫生间外墙的"服务带"排布（管线集中）。
- 吊柜到顶，台面下做嵌入式电器。
- 吧台可兼"餐区 + 软隔断 + 工作台"三用。

### 休闲
- 沙发选小三人以内 / 双人 / 沙发床。
- 茶几可选；优先**可升降 / 折叠边几**，或与沙发床/墨菲床区复用地面。

### 储物
- **到顶定制柜**：参数化，按可用墙长伸缩。
- 玄关过渡区做**薄鞋柜（深度 ≤ 350mm）+ 壁挂**。
- 善用床下、沙发下、楼梯下等剩余体积。

## 三、尺寸纪律

- **【必须】**不编造家具尺寸——只用 `module_library.json` 里定义的尺寸或其 parametric limits 内的取值。
- **【必须】**parametric 件调尺寸必须落在 `limits` 内且对齐 `step`。
- **【建议】**优先选库里 depth 更小的同功能件——小空间进深比面宽更敏感。

## 四、与软分区/效率的衔接

- 选品服务于软分区方案：先有"这个区是睡眠且与休闲复用"，再选"墨菲床"。不要反过来先选家具再硬凑功能。
- 多用途件直接拉高 `evaluate_efficiency` 的**功能复用率**指标——这是小空间的核心分数。
